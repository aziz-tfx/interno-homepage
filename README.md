# INTERNO School — главная страница

Хоум-пейдж школы современных профессий (референс структуры — proweb.uz): hero с видео-фоном, каталог направлений со ссылками на лендинги курсов, преимущества, форматы обучения, CTA открытого урока.

## Структура

Один самодостаточный `index.html` (стили и скрипты инлайном) + папка `assets/`.
Узбекская версия `uz/index.html` генерируется из него — см. «SEO» ниже.

Дизайн: тёмные и «бумажные» секции чередуются, заголовки набраны Oswald капсом, фиолетовые плашки-теги, лаймовые маркеры-«скотч», bento-сетки с фотографиями. Секции: hero «одна комната — семь профессий» → направления (раскрывающиеся полосы) → портфолио → почему мы → менторы → форматы → CTA открытого урока.

### Hero: одна комната — семь профессий

Hero на весь экран: пустая бетонная комната по очереди превращается в сцену каждого направления
(интерьер → архитектура → графдизайн → видеомонтаж → data → AI → бухгалтерия). Сцены и переходы
сгенерированы в Higgsfield (кадры — GPT Image 2.5, переходы — MiniMax H3 по первому и последнему кадру),
лежат в `assets/hero/`:

- `s0` — пустая комната, `s1`…`s7` — сцены направлений (кадры-заглушки, `.jpg`);
- `t1`…`t7` — переход в сцену `k` из сцены `k-1` (`.webm` VP9 и `.mp4` H.264, без звука);
- суффикс `-d` — горизонтальная версия 16:9, `-m` — вертикальная 9:16 для телефонов и вертикальных планшетов.

Сцены показываются по кругу (3,5 с на сцену), табы переключают направление вручную и выключают автопоказ.
Видео грузятся по одному, следующее — заранее в фоне; если видео не загрузилось или автозапуск запрещён
(режим энергосбережения iOS), сцена меняется плавной сменой кадра. При «уменьшить движение» и экономии
трафика видео не грузятся совсем. Вертикальные кадры `-m` используют и полосы секции «Направления».

Пересобрать ассеты из исходников Higgsfield (`t1-d.mp4 … t7-m.mp4` в одной папке): `scripts/build-hero.sh <папка>` (нужен ffmpeg).

- Фото секций сгенерированы в Higgsfield (GPT Image 2.5) и лежат в `assets/photos/*.jpg` (список — `scripts/photos.json`).
  Их скачал `scripts/localize-photos.py` (нужен Pillow) — пригодится, если добавятся новые фото с CDN Higgsfield.
- `assets/mentor-*.jpg` — фото менторов
- `assets/logo.svg` — логотип школы
- `assets/icon-*.png`, `assets/hero-bg.png`, `assets/hero-loop.mp4`, `float-cap.png` — материалы прошлой версии, в текущей вёрстке не используются

Деплой на любой статический хостинг: Vercel, Netlify, GitHub Pages.

## SEO и LLM

Русская версия — `/`, узбекская — `/uz/` (отдельные URL, чтобы поисковики и LLM индексировали оба языка).
Тексты правятся только в `index.html` (разметка + словарь `I18N`), после правок:

```bash
node scripts/build-seo.mjs   # uz/index.html, SEO-блок <head> с JSON-LD, sitemap.xml, robots.txt, llms.txt
node scripts/build-og.mjs    # OG-картинки assets/og.jpg и og-uz.jpg (шаблон scripts/og.html, нужен Playwright)
```

Что сделано, чек-лист для лендингов курсов и внешние шаги — `docs/seo-geo.md`.

## Заявки → amoCRM

Все кнопки записи (`data-modal-open`) открывают одну форму `#homepage_modal`. Заявка уходит в
форму amoForms **1751306**: сначала через `api/lead.js` (Vercel Function проверяет ответ amo,
`error_code === 0`), а если функция недоступна — напрямую из браузера на `forms.amo-forms.ru`.
Параллельно уходит уведомление в Telegram. Имена полей (`AMO_FIELDS`) — общие поля аккаунта;
если форму в amo пересоздадут с другими полями, обновите их в `api/lead.js` и `index.html`.

## Акция 11.11 — `/aksiya/`

Промо-лендинг по ТЗ «акция 11.11» (второй курс в подарок) в дизайн-системе главной: те же токены,
шапка, футер, теги, маркер-«скотч», bento-карточки и попап. `aksiya/index.html` — один файл
со стилями и скриптами; свои картинки — в `aksiya/img/`, остальное переиспользуется из `assets/`.
Короткая ссылка для рекламы — `/1111` (страница `1111/index.html` перекидывает на `/aksiya/`
и сохраняет UTM-метки; работает на любом хостинге).

- **Дата окончания акции** — константа `PROMO_END` в начале `<script>` (сейчас `2026-11-15 23:59`, Ташкент).
  По ней считают оба таймера и подпись «Акция до …» в hero.
- **Hero** — та же пустая комната, что на главной (`assets/hero/s0`), в ней появляется подарок:
  кадры `img/hero-{d,m}.jpg` и переход `img/hero-{d,m}.{webm,mp4}` сделаны в Higgsfield
  (кадр — GPT Image 2.6 по `s0`, переход — Seedance 2.5 из `s0` в кадр с подарком). Видео
  проигрывается один раз и заканчивается на кадре hero; при «уменьшить движение» и экономии трафика не грузится.
- **Карточки курсов и подарков** — сцены направлений с главной (`assets/hero/s*-m.jpg`, `s*-d.jpg`),
  «Почему INTERNO» — фото из `assets/photos/` (без людей, как в ТЗ).
- **Заявки** — форма amoForms 1751306: `/api/lead`, если он отвечает `{"ok":true}`, иначе напрямую в amo
  + уведомление в Telegram. Имя сделки: `Акция 11.11 · Имя · Город`; в заметке первой строкой
  «🔥 Акция 11.11», затем курс, подарок, город и UTM.
- **Meta Pixel** INTERNO School Pixel `4251277901808457`: `PageView` при загрузке, `Lead` — после отправки формы.
