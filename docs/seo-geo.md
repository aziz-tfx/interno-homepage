# SEO и видимость в LLM (GEO) — INTERNO School

Цель: чтобы по запросам «курсы дизайна интерьера Ташкент», «data-analitika kurslari», «где учиться бухгалтерии
в Самарканде» и т. п. в Google/Яндексе и в ответах ChatGPT, Claude, Perplexity, Gemini и Алисы находились наши сайты.
Код даёт техническую базу. Места в выдаче решают ещё контент, отзывы, карты и ссылки (раздел 3).

## 1. Что сделано на главной (internoedu.uz)

| Что | Зачем |
|---|---|
| `/uz/` — отдельная узбекская страница (генерируется из словаря `I18N`) | раньше UZ-текст подменялся скриптом, и поисковики видели только русский. Теперь узбекские запросы получают свою страницу |
| `hreflang` ru/uz + `canonical` | Google и Яндекс показывают нужный язык и не считают страницы дублями |
| Title/description под запросы «курсы … в Ташкенте» на двух языках | сниппет и ранжирование по коммерческим запросам |
| JSON-LD: `EducationalOrganization`, 7 × `Course`, менторы (`Person`), `FAQPage` | структурированные факты, которые поисковики и LLM берут в карточки и ответы |
| Блок FAQ (7 вопросов, RU/UZ) со ссылками на все лендинги | прямые ответы на вопросы, которые чаще всего цитируют LLM, и внутренние ссылки на курсы |
| `robots.txt` с явным доступом для AI-краулеров (GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended, YandexAdditional…) + `Clean-param` для UTM | LLM могут читать сайт; у Яндекса не появляются дубли страниц с UTM-метками |
| `sitemap.xml` с языковыми альтернативами | быстрая индексация обеих версий |
| `llms.txt` — сводка о школе, курсах, менторах и FAQ в Markdown | готовый к цитированию конспект для LLM-агентов |
| OG-картинки RU/UZ, фавиконки | превью в Telegram/Instagram/поиске → выше CTR |
| `vercel.json`: `noindex` на `interno-homepage.vercel.app`, кэш ассетов | нет дубля на техническом домене, быстрее повторные загрузки |

### Как поддерживать

Тексты правятся только в `index.html` (разметка + словарь `I18N`), затем:

```bash
node scripts/build-seo.mjs   # пересобирает uz/index.html, SEO-блок <head>, sitemap, robots, llms.txt
node scripts/build-og.mjs    # только если меняли OG-картинки (нужен Playwright)
```

`uz/index.html` руками не редактировать — он перезаписывается.

## 2. Чек-лист для каждого лендинга курса (поддомены)

Применить на interior / architecture / graphic / videomontaj / data / ai / buxgalteriya:

- [ ] Отдельные индексируемые URL на RU и UZ (не JS-переключатель) + `hreflang` + `canonical`
- [ ] Title: «Курс <профессия> в Ташкенте — офлайн | INTERNO», description с ценой/сроком/форматом
- [ ] Один `<h1>` с главным запросом; программа курса — текстом в HTML, не картинками
- [ ] JSON-LD `Course` с реальными данными: `offers` (цена, UZS), `hasCourseInstance` (`courseMode`, `courseWorkload`, даты старта, город), `provider` → INTERNO School. С заполненными ценой и длительностью курс может попасть в расширенные сниппеты Google
- [ ] FAQ по курсу: цена, длительность, расписание, нужен ли опыт, ноутбук, сертификат, трудоустройство — и `FAQPage`
- [ ] Ссылка на главную `https://internoedu.uz/` и на 2–3 соседних курса (перелинковка)
- [ ] `robots.txt`, `sitemap.xml`, `llms.txt`, OG-картинка, фавикон
- [ ] Скорость: LCP < 2,5 с на мобильном (сжатые WebP/AVIF, `loading="lazy"`, без тяжёлых видео в первом экране)
- [ ] `alt` у содержательных изображений (работы студентов, менторы)

## 3. Вне кода — без этого первых мест не будет

1. **Google Search Console и Яндекс Вебмастер** — подтвердить `internoedu.uz` (доменный ресурс покрывает все поддомены), отправить sitemap каждого сайта, смотреть запросы и ошибки индексации.
2. **Bing Webmaster Tools** — импорт из Search Console в один клик. ChatGPT Search и Copilot опираются на индекс Bing.
3. **Карты**: Google Business Profile, Яндекс Бизнес и 2GIS — отдельная карточка на каждый филиал (Ташкент, Самарканд, Фергана) с точным адресом, часами, фото и ссылкой на сайт. Когда будут адреса — добавить их в `address` JSON-LD и в футер сайта.
4. **Отзывы** на картах и в Google: просить каждого выпускника. Количество и свежесть отзывов — главный фактор локальной выдачи; LLM их тоже цитируют.
5. **Упоминания и ссылки**: каталоги курсов Узбекистана, статьи в медиа (Kun.uz, Spot.uz, Gazeta.uz), интервью менторов, посты партнёров. LLM рекомендуют то, что часто и одинаково упоминается в независимых источниках.
6. **Контент под запросы**: статьи/страницы «Сколько зарабатывает дизайнер интерьера в Узбекистане», «Как стать data-аналитиком с нуля», страницы по городам («Курсы дизайна в Самарканде»). Каждая — на RU и UZ.
7. **Единое название везде**: «INTERNO School», телефон +998 78 113 18 08, одинаковые ссылки в Instagram/Telegram/картах — так поисковики и LLM склеивают упоминания в одну сущность.
8. **Проверка видимости в LLM** раз в месяц: задавать ChatGPT/Perplexity/Gemini/Алисе 10–20 типовых вопросов («лучшие курсы дизайна интерьера в Ташкенте») и записывать, упоминают ли INTERNO и какие источники цитируют.
